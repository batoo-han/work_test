## Cursor Rules и Skills

**Rules** — использую, но не всегда. Своих правил немного, ключевые два:

1. **Context7 по умолчанию** — при генерации кода, установке, настройке или обращении к документации библиотеки/API агент автоматически использует MCP-инструменты Context7 для получения актуальной документации без явного запроса.

2. **Чек-лист перед продакшеном:**
   - проверка на уязвимости;
   - проверка на SQL-инъекции;
   - проверка на утечки памяти;
   - наличие системы логирования (несколько уровней, суммарный размер логов не более 100 МБ, старые удаляются автоматически);
   - очистка от лишних зависимостей;
   - проверка актуальности библиотек;
   - все секреты только в `.env`, не в документации и не в коде;
   - ревью кода;
   - анализ узких мест в производительности.

**Skills** — начал использовать недавно, понравилось.
