# Руководство пользователя

## Требования
- Python 3.12+
- Доступ к DNS и SMTP (порт 25 может быть заблокирован провайдером/фаерволом)

## Установка
1. Создайте виртуальное окружение:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Запуск
Пример запуска со списком адресов:
```
python src/email_domain_check.py test@example.com user@domain.tld
```

Опционально можно задать таймаут:
```
python src/email_domain_check.py test@example.com --timeout 8
```

## Результат
Для каждого адреса выводится статус домена и, при валидном домене, результат SMTP-проверки (handshake без отправки письма):

- **«домен валиден»** — с уточнением по SMTP:
  - «пользователь подтверждён по SMTP» — сервер принял RCPT TO;
  - «пользователь не найден по SMTP» — сервер явно отверг адрес;
  - «SMTP-проверка недоступна» — таймаут, порт 25 заблокирован или иная ошибка.
- **«домен отсутствует»** — домен не существует (NXDOMAIN).
- **«MX-записи отсутствуют или некорректны»** — MX не найдены или ошибка DNS.
