# Использование скрипта отправки в Telegram

Скрипт читает текст из указанного `.txt`-файла и отправляет его в выбранный приватный Telegram-чат через бота.

## Требования

- Python 3.12+
- Установленные зависимости из корня проекта:
  ```bash
  pip install -r requirements.txt
  ```

## Настройка

### 1. Токен бота (BOT_TOKEN)

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте подсказкам (имя и username бота).
3. В ответ BotFather пришлёт токен вида `123456789:ABCdefGHI...`. Это и есть `BOT_TOKEN`.

### 2. ID чата (CHAT_ID)

Чтобы скрипт мог отправлять сообщения в ваш приватный чат:

1. Напишите вашему боту любое сообщение (например, «Привет») в личку.
2. Откройте в браузере (подставьте свой токен):
   ```
   https://api.telegram.org/bot<BOT_TOKEN>/getUpdates
   ```
3. В ответе найдите `"chat":{"id": 123456789, ...}`. Число `123456789` — это ваш `CHAT_ID` для личного чата с ботом.

Для групп и каналов ID получают иначе (например, через ботов вроде @userinfobot для групп).

### 3. Файл .env

В корне проекта:

1. Скопируйте шаблон:
   ```bash
   copy .env.example .env
   ```
   (В Linux/macOS: `cp .env.example .env`.)

2. Откройте `.env` и заполните (без кавычек):
   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   CHAT_ID=ваш_chat_id
   ```

Файл `.env` не должен попадать в репозиторий (он уже указан в `.gitignore`).

## Запуск

Из корня проекта:

```bash
python src/telegram_send.py путь/к/файлу.txt
```

Пример:

```bash
python src/telegram_send.py message.txt
```

Отправить в другой чат без правки `.env`:

```bash
python src/telegram_send.py message.txt --chat-id 987654321
```

Таймаут запроса к API (по умолчанию 30 секунд):

```bash
python src/telegram_send.py message.txt --timeout 15
```

## Результат

- **Успех:** в консоль выводится строка «Сообщение успешно отправлено в Telegram.» и код выхода 0.
- **Файл не найден:** сообщение об ошибке в stderr, ненулевой код выхода.
- **Ошибка кодировки файла:** сообщение в stderr, ненулевой код выхода (файл должен быть в UTF-8).
- **Не задан BOT_TOKEN или CHAT_ID:** сообщение в stderr с указанием, чего не хватает.
- **Неверный токен или недоступный чат:** ответ Telegram API выводится в stderr (например, «Unauthorized» или «Bad Request: chat not found»).
- **Ошибка сети:** сообщение в stderr о неудачном запросе.
